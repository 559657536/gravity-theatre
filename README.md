# 引力剧场 · Gravity Theatre

给 Luo 的一份可以留下的宇宙。2026-10-21。

五种实时生成的星空，可以牵引、推开、环绕、点燃，调节时间与光，听生成式和声，保存 1800 × 1125 像素的宇宙明信片。

## 打开

直接双击 `引力剧场.html`。这是完整的离线版，不需要安装、不需要 API Key、不需要会员或联网。也可以打开 `dist/index.html`。

如需通过本地 HTTP 预览，在本目录运行：

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory dist
```

然后访问 `http://127.0.0.1:8766`。

## 操作

- 按住星空拖动：使用当前工具；滚轮缩放。
- `1` / `2` / `3`：牵引 / 推开 / 环绕。
- `空格`：暂停或继续；`B`：点燃星空。
- `H`：沉浸模式；`M`：声音开关。
- 「让宇宙自己讲述」：60 秒、五幕漫游。
- 「把此刻带走」：保存 PNG 明信片或收藏场景、种子、视角和参数；收藏保存在当前浏览器本机，最多 6 条。收藏恢复的是场景初态和设置，不是每一颗粒子的瞬时轨迹。

声音默认关闭，需点击开启。使用浏览器原生 Web Audio 实时生成，不请求网络。

## 源码

- `dist/engine.js`：Astra 实现的 WebGL 粒子引擎，含 Canvas2D 回退。
- `dist/app.js`：交互、声音、明信片、本机收藏。
- `dist/style.css`：响应式界面。
- `dist/index.html`：作品页面。

视觉与运动是受引力启发的生成艺术，不是精确天体物理模拟。WebGL 下约 1.8 万粒子，Canvas2D 回退粒子较少。已考虑减少动态效果的系统偏好。建议使用近期 Chrome 或 Edge；性能随设备而异。

## 重新生成单文件离线版

```powershell
node package-offline.cjs
```

页面不依赖外部素材、字体或 JavaScript 库。在线私有版的访问受站点平台账号与服务状态影响；本地离线版不依赖在线版。
